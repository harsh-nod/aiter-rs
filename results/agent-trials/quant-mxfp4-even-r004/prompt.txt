# gfx950 MXFP4 Even quantization

The input is a contiguous, 16-byte-aligned `X[M,K]` matrix of FP16 (`dtype=0`)

is divisible by 32. Values are finite normal numbers or signed zero with
absolute value at most 128. Output pointers address distinct preallocated

outside the output spans, use the supplied HIP stream, and do not synchronize.

For each 32-value group, convert to FP32 and take `amax=max(abs(x_i))`.
Compute the scale with this Even-mode rule:

```text
r_bits = (bits_f32(amax) + 0x00200000) & 0x7F800000
exponent = -127 if r_bits == 0 else clamp(exponent_bits(r_bits)-129, -127, 127)
scale = 2^exponent
```

Divide each value by `scale`, round to nearest E2M1 level with ties to the
even code, and saturate at magnitude 6. The positive levels by code are
`0, 0.5, 1, 1.5, 2, 3, 4, 6`; bit 3 is the sign, including negative zero.
Pack even-indexed values in low nibbles and odd-indexed values in high
nibbles. Scale bytes are row-major.
